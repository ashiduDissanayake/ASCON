# Setting Up the ASCON Project in Vivado

## Step 1: Create the Vivado Project
1. Open Vivado and click **Create Project**.
2. Set the location to the root of this cloned repository (e.g., `ASCON/`). 
3. Select **RTL Project** and check "Do not specify sources at this time".
4. Select your target FPGA part or board, and click **Finish**.

## Step 2: Add Design and Simulation Sources
Once the empty project is open, you need to link the Verilog files.
1. In the Flow Navigator, click **Add Sources**.
2. Select **Add or create design sources** and click Next.
3. Click **Add Directories**, navigate to the root repository, and select the `rtl/` folder. Click Finish.
4. Click **Add Sources** again, select **Add or create simulation sources**, and click Next.
5. Click **Add Directories**, navigate to the root repository, and select the `tb/` folder. Click Finish.

*(Note: Ensure that `tb/tb_common.vh` is recognized as a header file by the simulator).*

## Step 3: Configure the TCL Environment
To ensure the testbenches can locate external files and references, set up the root repository path in the Vivado TCL console.

Run the following commands in the TCL console at the bottom of the Vivado GUI (modify the path to match your local machine's clone location):

```tcl
set ::env(ASCON_REPO_ROOT) "REPO_ROOT_PATH"
cd $::env(ASCON_REPO_ROOT)
```

## Step 4: Configure the Simulation Sandbox
This project uses file-driven testbenches that read vectors generated by the Python reference model. Vivado runs simulations in a hidden sandbox directory, so you must manually copy the test vectors there to avoid file read errors.

1. Copy the entire `vectors/` folder from the root repository.
2. Navigate into your newly created Vivado project folder and locate the simulation sandbox: `vivado_work.sim/sim_1/behav/xsim/`
3. Paste the `vectors/` folder directly into that `xsim/` directory.
